## 🌟 نبذة عن النظام
نظام ويب متكامل وفعلي لإدارة الموارد البشرية وحضور وانصراف موظفي مؤسسة الفجر الخيرية الاجتماعية، مبرمج بتقنيات الويب الحديثة ومتصل سحابياً تلقائياً مع دعم كامل للمزامنة اللحظية بين جميع الأجهزة (الهواتف الذكية وأجهزة الكمبيوتر).

### ✨ المميزات الرئيسية
- 📱 **واجهات محسنة ومخصصة للهواتف الذكية (Android & iOS):** شريط تنقل سفلي سريع (Bottom Navigation Bar)، قوائم منسدلة جانبية متجاوبة، وتجربة مستخدم سلسة.
- 💻 **لوحة تحكم إدارية شاملة للكمبيوتر:** إحصائيات بيانية، جداول تفاعلية، وطباعة رسمية A4.
- ☁️ **ربط سحابي تلقائي ومباشر (Cloud Sync Engine):** متصل سحابياً وجاهز للعمل فور رفعه على **GitHub / GitHub Pages** دون الحاجة لأي إعدادات يدوية معقدة.
- 🔄 **مزامنة فورية بين الأجهزة:** أي حضور أو طلب إجازة يسجله الموظف من هاتفه يظهر فورياً على شاشة إدارة المؤسسة في الكمبيوتر والعكس.
- 📍 **نظام حضور مرن (GPS & الحضور السحابي):**
  - يدعم الحضور الميداني بالتحقق الجغرافي الدقيق عبر **GPS** ومعادلة **Haversine**.
  - يدعم خيار **الحضور السحابي من أي مكان (عن بُعد)** بدون قيود المسافة لتسجيل الدوام من خارج المقر.
- ⏱️ **الحساب الدقيق للتأخير وفترة السماح:** احتساب التأخير بالثواني والدقائق (فترة سماح 15 دقيقة، وإذا تجاوزها الموظف يُحسب التأخير بالكامل من بداية الدوام).
- 💰 **قسم مخصص «💰 راتبي» للموظف:** احتساب آلي وفوري للأجر اليومي وأجر الساعة وأجر الدقيقة وإجمالي الخصومات وصافي الراتب.
- 🏖️ **إدارة الإجازات والأرصدة:** خصم آلي من رصيد الإجازات السنوية، أنواع إجازات متعددة، وموافقة/رفض الإدارة.
- 📝 **نظام الأعذار الإلكتروني:** تقديم الأعذار مع إمكانية إرفاق التقارير وإسقاط خصم التأخير تلقائياً فور موافقة الإدارة.
- 🖨️ **تقارير وطباعة A4 وتصدير CSV:** كشوفات دوام رسمية، مسيرات رواتب، وتصدير إكسل بنقرة زر.

## 🚀 طريقة الرفع على GitHub وتشغيل الموقع سحابياً (GitHub Pages)

تم تجهيز المشروع بالكامل ليعمل سحابياً ومباشرة عند رفعه على **GitHub**. اتبع الخطوات البسيطة التالية:

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح موقع [GitHub.com](https://github.com/) وقم بتسجيل الدخول إلى حسابك.
2. اضغط على زر **New** لإنشاء مستودع جديد (Repository).
3. سمّ المستودع مثلاً: `fjr-attendance` أو `alfajr-charity`.
4. اجعل المستودع **Public** (عام) ثم اضغط **Create repository**.

### الخطوة 2: رفع ملفات المشروع إلى المستودع
يمكنك رفع الملفات عبر أي من الطرق التالية:
- **الطريقة الأسهل (عبر متصفح الويب):**
  1. في صفحة المستودع الجديد على GitHub، اضغط على **uploading an existing file**.
  2. اسحب جميع ملفات ومجلدات مجلد `D:\fjr` (الملفات: `index.html`, `login.html`, `admin.html`, `employee.html`, ومجلدات `css`, `js`, `assets`) وأفلتها في المتصفح.
  3. اكتب وصفاً للرفع واضغط **Commit changes**.

- **أو عبر تطبيق GitHub Desktop / Git Bash:**
  ```bash
  git init
  git add .
  git commit -m "الإصدار السحابي المتكامل لمؤسسة الفجر الخيرية"
  git branch -M main
  git remote add origin https://github.com/اسم_حسابك/fjr-attendance.git
  git push -u origin main
  ```

### الخطوة 3: تفعيل الاستضافة السحابية المجانية (GitHub Pages)
1. من داخل صفحة المستودع على GitHub، اذهب إلى تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية اختر **Pages**.
3. في قسم **Build and deployment > Branch**:
   - اختر الفرع: **`main`**
   - اختر المجلد: **`/ (root)`**
   - اضغط **Save** (حفظ).
4. خلال دقيقة واحدة، سيظهر لك رابط الموقع السحابي المباشر بالأعلى:
   ```
   https://username.github.io/fjr-attendance/
   ```
5. افتح هذا الرابط من **هاتف الأندرويد** أو من **الكمبيوتر**، وسيعمل النظام سحابياً وتتزامن البيانات تلقائياً بين جميع الأجهزة!
