## 🌟 نبذة عن النظام
نظام ويب متكامل وفعلي لإدارة الموارد البشرية وحضور وانصراف موظفي مؤسسة الفجر الخيرية الاجتماعية باستخدام تقنيات الويب الحديثة وحوسبة **Google Firebase**.

يدعم النظام:
- 📱 الهواتف الذكية.
- 💻 أجهزة الكمبيوتر والمكتب.
- 📲 الأجهزة اللوحية (Tablets).
- 🌐 اللغة العربية بالكامل واتجاه RTL.
- 📍 التحقق الجغرافي الدقيق للحضور والانصراف عبر تقنية **Browser Geolocation API** ومعادلة **Haversine**.
- ⏱️ الحساب الدقيق للتأخير بالثواني وفترة السماح المعتمدة.
- 💰 الحساب الآلي والآني لخصومات التأخير والأجر اليومي وأجر الساعة وأجر الدقيقة وصافي الراتب.
- 🏖️ إدارة الإجازات والأرصدة والخصم الذري عبر **Firestore Transactions**.
- 📝 نظام متكامل للأعذار مع إسقاط الخصم آلياً عند قبول العذر.
- 📊 تقارير تفصيلية جاهزة للطباعة القياسية A4 والتصدير بصيغة CSV.

## 📐 القواعد الدقيقة لاحتساب التأخير والرواتب

### 1. قاعدة فترة السماح والتأخير:
- **بداية الدوام:** `07:00:00`
- **فترة السماح:** `15 دقيقة`
  - الحضور حتى `07:15:00` ⬅️ **التأخير المحتسب = 0 دقيقة | الخصم = 0 ريال**.
  - الحضور الساعة `07:16:00` ⬅️ **التأخير المحتسب = 16 دقيقة كاملة** (وليس دقيقة واحدة، لأن فترة السماح تم تجاوزها بالكامل).
  - الحضور الساعة `07:16:35` ⬅️ **التأخير المحتسب = 16 دقيقة و35 ثانية** (يحفظ النظام الثواني بدقة).

### 2. معادلات الراتب:
- **الأجر اليومي** = `الراتب الشهري ÷ 30 يوماً` (مثال: `120000 ÷ 30 = 4000 ريال`).
- **أجر الساعة** = `الأجر اليومي ÷ 7 ساعات` (مثال: `4000 ÷ 7 = 571.43 ريال`).
- **أجر الدقيقة** = `أجر الساعة ÷ 60` (مثال: `571.43 ÷ 60 = 9.52 ريال`).
- **قيمة الخصم** = `دقائق التأخير المحتسبة × أجر الدقيقة`.
- **صافي الراتب** = `الراتب الشهري - إجمالي خصومات التأخير`.
- **أثر قبول العذر:** عند موافقة الإدارة على عذر التأخير، يتم إسقاط التأخير المحتسب ويصبح الخصم `0 ريال` فوراً وتُعاد حسابات صافي الراتب تلقائياً.

## 🚀 خطوات الإعداد والتشغيل السريع

### 1. إنشاء مشروع Firebase:
1. توجه إلى [Firebase Console](https://console.firebase.google.com/).
2. اضغط **Add Project** وقم بتسميته (مثلاً: `al-fajr-charity`).

### 2. تفعيل الخدمات في Firebase Console:
- **Authentication:**
  - اذهب إلى **Build > Authentication > Get Started**.
  - فعّل موفر تسجيل الدخول **Email/Password**.
- **Cloud Firestore:**
  - اذهب إلى **Build > Firestore Database > Create Database**.
  - اختر وضع البدء **Production Mode** وحدد الموقع الجغرافي الأقرب (مثلاً: `asia-south1` أو `europe-west1`).
- **Firebase Storage:**
  - اذهب إلى **Build > Storage > Get Started**.

### 3. ربط إعدادات المشروع في الكود:
افتح الملف `js/firebase-config.js` واستبدل كائن `firebaseConfig` بمعلومات تطبيق الويب الخاص بك من إعدادات المشروع:
```javascript
const firebaseConfig = {
  apiKey: "مفتاح_API_الخاص_بك",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "...",
  appId: "..."
};
```

### 4. نشر قواعد الأمان (Security Rules):
باستخدام أداة **Firebase CLI**:
```bash
# تسجيل الدخول
firebase login

# اختيار المشروع
firebase use your-project

# نشر القواعد
firebase deploy --only firestore:rules,storage
```

### 5. تشغيل النظام محلياً:
يمكنك تشغيل المشروع بأي خادم ويب محلي:
```bash
# عبر Python
python -m http.server 8080

# أو عبر Node/npx
npx serve .
```
ثم افتح المتصفح على `http://localhost:8080`.

### 6. النشر على استضافة Firebase Hosting:
```bash
firebase deploy --only hosting
```
سيصبح النظام متاحاً على رابط عام ومحمي بشهادة SSL تلقائية.
